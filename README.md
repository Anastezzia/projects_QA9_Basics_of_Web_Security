### Задание 1. Виды безопасности

1. Дайте определение каждому виду безопасности.
2. Дайте определение каждой причине безопасности.

### Задание 2. Инструменты криптографии

1. Дайте определение каждому из перечисленных инструментов криптографии.
2. Изучить и выписать определение симметричного и асимметричного шифрования.
3. Выписать плюсы и минусы симметричного и асимметричного шифрования.
4. Выписать 2–3 слабых алгоритмов симметричного шифрования (которые могут быть быстро взломаны) и 1–2 безопасных.
5. Выписать 1–2 алгоритма хеширования, не рекомендованных к использованию, и 1–2 рекомендованных (стойких к различным атакам).
